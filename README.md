[README.md](https://github.com/user-attachments/files/34037983/README.md)# Travel Assistant Backend (MVP)

Python 3.12 + FastAPI + SQLite. В первой версии ответы и цены **демонстрационные**: AI-агент и реальные API пока не подключены.

## Docker

```bash
docker compose up --build
```

Swagger UI: http://localhost:8000/docs
Health: http://localhost:8000/health

## Без Docker

```bash
python -m venv .venv
# Windows PowerShell:
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn app.main:app --reload
```

## Тестовый сценарий

1. В Swagger откройте POST /chat и отправьте `{"message":"Хочу на море на неделю"}`.
2. Скопируйте `session_id` из ответа.
3. В GET /trips/{session_id} посмотрите сохранённый план.
4. POST /bookings: `{"session_id":"<ваш session_id>","option_id":"demo-antalya"}`.
5. После перезапуска сервера записи сохранятся благодаря SQLite.

## Что реально, а что нет
- **Реально:** названия отелей, звёзды (где указаны), адреса, правила проживания (дети, животные, питание), расстояния. Источники: `source_urls`, дата проверки: `verified_date`.
- **Оценочно:** все цены отелей (`price_source: "estimate"`, пояснение в `price_note`).
- **Вымышленно:** весь транспорт и трансферы (названия перевозчиков, цены, время, наличие мест). На демо говорим об этом прямо.

## Правила для агента
- Все цены в RUB. Даты доступности условные: 2026-11-01 .. 2026-12-31 (реального наличия мест нет).
- `null` у реального отеля = **неизвестно**, не "нет". Агент говорит: "в источниках не нашёл, уточните в отеле". Список таких полей: `unverified_fields`.
- Минимальные ночи, лимит гостей, условия отмены и закрытые даты у реальных отелей неизвестны (`null` или пустой список). Агент не должен выдумывать их.
- Отель: цена за номер за ночь. Транспорт: `price_per_adult`, ребёнок = цена x `child_price_multiplier`, младше `infant_free_under_age` бесплатно. Трансфер: `price_basis` = `per_person` или `per_vehicle`.
- `distance_to_airport_km`: Кемер (Alexius, L'Oceanica) далеко от аэропорта Антальи, для них нужны трансферы в Кемер.
- Животные: должны подходить отель, транспорт и трансфер одновременно (`pets_allowed`).
- Купаться в ноябре в этом каталоге нельзя нигде (`sea_swimming_possible_november` = false), горных и всех зарубежных тёплых направлений кроме Антальи нет.
